`hap-counter`: given read alignments (in BAM format with haplotype tags) and a set of variants (in phased VCF format) computes support for ALT and REF alleles across reads assigned to individual haplotypes.

# Installation

```bash
git clone git@github.com:iam28th/hap-counter.git --recurse-submodules
# submodules contain specification and test files, omit 
# if they're not necessary
```
